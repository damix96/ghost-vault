## Граница результата

Настройку соединения и ручного секрета проверил через видимые изменения интерфейса. Подключение внешнего клиента, отправку запроса, автоматическое обнаружение в реальном тексте и восстановление ответа не выполнял. Поэтому «защита работает» из этого пути не следует.

Два неуспешных поиска поля по видимому placeholder были ошибками неоднозначности браузерного помощника, после них использовал координаты. Они не изменили пользовательские данные и не считаются дефектами интерфейса. Промежуточные PNG этих действий сохранены в screenshots; основные наблюдения выше ссылаются на просмотренные значимые состояния.
