# Независимое исследование «Обзора» с дизайн-навыком

Согласованный шаблон: 2026-10-30. Отдельное исследование, не продолжение прежнего пользовательского UX-аудита. Каждый агент получает один навык, отдельную headless-сессию и папку результатов; без истории обсуждений и чужих отчётов. Цель разделения — сравнить самостоятельные выводы навыков без подсказанного списка недостатков. Критерии отбора координатора агентам не передавать.

Перед запуском заменить все поля в квадратных скобках реальными значениями. Техническая инструкция оператора: [overview-browser-operator.md](overview-browser-operator.md). Не дополнять поручение прежними шкалами, обязательными маршрутами или методикой оценки.

## Промпт агенту

Используй навык **[НАЗВАНИЕ]**.

Исследуй страницу **«Обзор»** GhostVault: **[URL]**.

Цель — оценить UX/UI и найти проблемы на этой странице.

Изучи страницу визуально через скриншоты и посмотри относящийся к ней код. Свободно взаимодействуй с интерфейсом, включая окна и действия страницы «Обзор». Другие разделы не исследуй.

Не читай предыдущие исследования, отчёты других агентов и историю обсуждений. Код не изменяй.

**Браузер:** тебе предоставлена отдельная headless-сессия Chrome. Управляй ею через готовый скрипт:

```powershell
& 'D:\tools\anaconda\python.exe' `
  'E:\projects\aegis-gate\scripts\browser_operator.py' `
  --session '[ПУТЬ К ТВОЕЙ СЕССИИ]' `
  --action screenshot
```

Инструкция по командам: **[ПУТЬ К ИНСТРУКЦИИ ОПЕРАТОРА]**. Скрипт поддерживает клики, наведение, ввод, прокрутку и другие действия. Полученные скриншоты открывай инструментом просмотра изображений. Окна на экране пользователя не открывай.

Сохрани результаты в **[ПАПКА]/report.md**, скриншоты — в **[ПАПКА]/screenshots/**.
