# Техническая инструкция оценщику Codex

Использовать вместе с общим промптом UX/UI-исследования. Организатор подставляет SESSION, OUTPUT и URL. Браузер уже запущен headless через `scripts/browser_operator.py`; он остаётся открытым между командами. Код скрипта читать или переписывать не требуется.

Команды выполняй инструментом `exec_command` через PowerShell. Python: `D:\tools\anaconda\python.exe`. Скрипт: `E:\projects\aegis-gate\scripts\browser_operator.py`.

Получить текущий скриншот:

```powershell
& 'D:\tools\anaconda\python.exe' 'E:\projects\aegis-gate\scripts\browser_operator.py' --session 'SESSION' --action screenshot
```

JSON содержит `status`, `screenshot`, `cursor`, `url`, при ошибке — `error`. Обязательно открой путь `screenshot` инструментом `view_image` и посмотри изображение. Успешная запись PNG без его просмотра не считается визуальной оценкой. Ошибка команды не доказывает ошибку интерфейса: сначала прочитай её и посмотри полученный снимок.

Далее используй тот же вызов с нужными аргументами. Это словарь возможностей, не маршрут и не список обязательных действий:

| Намерение | Аргументы |
|---|---|
| Нажать видимый текст | `--action click --target 'ТОЧНЫЙ ТЕКСТ СО СКРИНШОТА'` |
| Навести курсор | `--action hover --target 'ТОЧНЫЙ ТЕКСТ СО СКРИНШОТА'` |
| Нажать элемент без текста/при неоднозначности | `--action click --x 420 --y 260` — координаты выбрать самому по текущему скриншоту |
| Ввести в выбранное поле | `--action type --value 'ВЫМЫШЛЕННЫЕ ДАННЫЕ'` |
| Выбрать поле по видимому placeholder и заменить ввод | `--action type --target 'PLACEHOLDER' --clear --value 'ВЫМЫШЛЕННЫЕ ДАННЫЕ'` |
| Нажать клавишу | `--action key --key TAB` либо ENTER, ESCAPE, ARROW_DOWN, BACKSPACE |
| Удерживать модификатор | `--action keydown --key CONTROL`, затем действие, затем `--action keyup --key CONTROL` |
| Прокрутить область под указателем | `--action scroll --x 900 --y 600 --dy 500`; отрицательное dy — вверх |
| Изменить размер области просмотра | `--action resize --width 390 --height 844` |
| Назад/вперёд/перезагрузка | `--action back`, `--action forward`, `--action reload` |
| Получить снимок после анимации | `--action screenshot --wait 1.5` |
| Завершить браузер после отчёта | `--action close` |

Каждое действие возвращает новый PNG. После значимого действия открой его. Между командами браузер сохраняет страницу, поля, фокус, открытые формы, scroll и удерживаемые модификаторы. Обязательно отпускай модификаторы. Не начинай новый процесс браузера на каждом шаге.

Поиск цели использует точный текст/placeholder, видимый в текущей области, включая Shadow DOM. Не придумывай невидимые подписи, CSS-селекторы и внутренние ID. Если совпадений несколько, не выбирай наугад: посмотри скриншот и нажми по координатам. Перед кликом по старым координатам после прокрутки/resize/изменения страницы сначала получи свежий снимок. Ввод без target/x/y идёт в текущий фокус. Окно браузера не появляется на рабочем столе.

Тип курсора читается только под указателем; PNG обычно не содержит сам указатель. Совпадение текста не гарантирует кликабельность: родительский label, перекрытие и disabled-состояние оцениваются визуально. Инструмент не предоставляет DOM-дампы, скрытый текст, API-ответы или выполнение произвольного JavaScript. Смена headless на видимое окно без согласования запрещена.

Результаты: `OUTPUT/report.md`, `OUTPUT/journey.md`; скриншоты автоматически записываются в `OUTPUT/screenshots/`, протокол команд — `OUTPUT/actions.jsonl`. В отчёте относительные ссылки на соответствующие PNG. Не перезаписывать чужие прогоны. Отчёт и journey можно записывать штатным файловым инструментом только в OUTPUT. Проект, настройки компьютера и файлы клиента не менять.

Если браузерный помощник недоступен или `view_image` не показывает картинки, сообщи организатору конкретную ошибку. Не подменяй компьютерное зрение чтением HTML. Никаких исправлений продукта или самостоятельного поиска нового инструмента.
