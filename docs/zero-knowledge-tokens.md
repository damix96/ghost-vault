# 02. Символические переменные (Zero-Knowledge Tokens)

Спецификация детерминированных символических псевдонимов `$${<NAME>}`, протокол двусторонней подстановки (Round-Trip) и сохранение Prompt Caching.

## Ограничения наивного маскирования

Традиционные DLP-инструменты заменяют конфиденциальные данные масками (`***`, `[REDACTED]`, случайные MD5/SHA256-хеши). В автономных агентных сценариях это вызывает критические сбои:

| Метод маскирования | Сбой в агентном цикле | Техническая причина |
|---|---|---|
| Звездочки (`***`, `[REDACTED]`) | Ошибки парсинга URI и аргументов CLI | `curl https://***:8080/api` вызывает `Invalid URL` в парсерах cURL, Fetch и Axios |
| Случайные хеши (`b4c8a2...`) | Потеря семантики и контекста сущности | Модель не способна определить назначение адреса (база данных, шлюз аутентификации, биллинг) |
| Одностороннее маскирование | Невозможность композиции вызовов тулов | Модель не может передать полученный адрес или токен в качестве параметра следующего шага |

## Спецификация Zero-Knowledge Symbolic Variables

Модель изолирована от реальных адресов и секретов, но получает строгую семантику сущности через символические псевдонимы:

```
https://internal.bank.kz/api/v1  ──►  $${<BANK_API_URL>}
https://auth.internal.bank.kz    ──►  $${<BANK_AUTH_URL>}
10.240.10.15                     ──►  $${<DB_PROD_HOST>}
eyJh... (JWT-токен)              ──►  $${<AUTH_JWT_TOKEN>}
```

### Инварианты формата токена

- **Синтаксис:** `$${<IDENTIFIER>}`.
- **Алфавит идентификатора:** строго `[A-Z0-9_]+`.
- **Изоляция от шаблонизаторов:** конструкция `$${<...>}` не конфликтует с Bash-переменными (`${VAR}`), Jinja/Liquid (`{{ var }}`), Terraform (`${...}`), PHP и Helm.
- **DLP-нейтральность:** не содержит доменных TLD, схем протоколов (`http://`, `https://`), IPv4/IPv6 октетов и высокоэнтропийных строк. Не триггерит корпоративные сетевые сигнатуры.
- **Регулярное выражение обратного поиска:** `/\$\$\{<([A-Z0-9_]+)>\}/g`.

## Жизненный цикл запроса (Round-Trip Execution Pipeline)

```
[ Пользователь / CLI ]
"Сделай запрос на https://internal.bank.kz/api/v1/users"
                          │
                          ▼
┌────────────────────────────────────────────────────────┐
│              GHOSTVAULT SINGLETON DAEMON               │
│                                                        │
│ 1. Детектор секретов (Aho-Corasick + Formats Index)    │
│    Обнаружено: "https://internal.bank.kz/api/v1/users" │
│                                                        │
│ 2. Проверка хранилища Vault:                           │
│    • Адрес известен: берем псевдоним                   │
│    • Новый адрес: применение политики (auto / popup)   │
│      Результат: $${<BANK_API_URL>}                     │
│                                                        │
│ 3. Исходящая замена:                                   │
│    "https://internal.bank.kz/api/v1/users"             │
│    ──► "$${<BANK_API_URL>}/users"                      │
└─────────────────────────┬──────────────────────────────┘
                          │ (В облачный API уходит ТОЛЬКО $${<NAME>})
                          ▼
               [ Облачная LLM (Anthropic) ]
   (Контекст: "Сделай запрос на $${<BANK_API_URL>}/users")
                          │
                          ▼ (Генерация tool_use)
    Tool Call: { command: "curl -s $${<BANK_API_URL>}/users" }
                          │
                          ▼
┌────────────────────────────────────────────────────────┐
│              GHOSTVAULT SINGLETON DAEMON               │
│                                                        │
│ 4. Распаковка аргументов вызова инструмента:           │
│    $${<BANK_API_URL>}/users ──►                        │
│    https://internal.bank.kz/api/v1/users               │
└─────────────────────────┬──────────────────────────────┘
                          │ (Локальное выполнение с РЕАЛЬНЫМ адресом)
                          ▼
         [ Локальный агент исполняет bash ]
          curl https://internal.bank.kz/...
                          │
                          ▼ (Вывод команды в stdout / stderr)
   "Error: Host https://internal.bank.kz unavailable"
                          │
                          ▼
┌────────────────────────────────────────────────────────┐
│              GHOSTVAULT SINGLETON DAEMON               │
│                                                        │
│ 5. Санитизация результата инструмента (tool_result):   │
│    https://internal.bank.kz ──► $${<BANK_API_URL>}     │
│    Новые обнаруженные секреты маскируются согласно     │
│    политике confirmationMode                           │
└─────────────────────────┬──────────────────────────────┘
                          │
                          ▼
               [ Облачная LLM (Anthropic) ]
  (Контекст: "Host $${<BANK_API_URL>} unavailable")
```

## Двусторонняя прозрачность интерфейса

1. **Исходящий поток (Outbound к LLM):** Передаются строго токены `$${<NAME>}`.
2. **Локальный терминал разработчика (Inbound SSE к CLI):** Через буфер скользящего окна (Sliding Window Buffer) демон выполняет обратную замену `$${<NAME>} -> Real` в чанках `text_delta`. Разработчик видит в консоли реальные рабочие адреса и параметры отладки.
3. **Сетевой уровень:** Корпоративные снифферы трафика на пути к облачным API фиксируют исключительно псевдонимы `$${<NAME>}`.

## Влияние на Prompt Caching (Anthropic / OpenAI)

Провайдеры современных моделей применяют побайтовое кеширование префиксов промптов:

- **Детерминированность префикса:** Системный промпт и история сообщений оперируют стабильными строками `$${<BANK_API_URL>}`. Ротация реальных токенов, смена динамических портов контейнеров или смена IP-адресов не приводят к инвалидации серверного кеша промптов.
- **Инвариант нулевой утечки (Zero-Disclosure Invariant):** Модель ни на одном этапе диалога не получает открытых байтов секрета в контекстное окно. Утечка секрета через атаки извлечения промпта (Prompt Extraction / Jailbreak) невозможна, так как секрет физически отсутствует в памяти модели.
