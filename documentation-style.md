# GhostVault Documentation Style (Agent-First)

## 1. Главный принцип
Документация пишется в первую очередь для AI-агентов (Agent-First). 
Цель: максимальная скорость и точность извлечения контекста языковой моделью при минимальном потреблении токенов внимания.

## 2. Сжатие формы без потери смысла (Zero Semantic Loss)
- Сжимаются речевые обороты, грамматический синтаксис и словесный шум.
- 100% технических нюансов, граничных случаев (edge cases) и ограничений сохраняются.

## 3. Обязательный контекст решений (Четыре вопроса)
Каждое техническое решение и архитектурный выбор должны содержать ответы на 4 вопроса:
1. **ПОЧЕМУ:** первопричина проблемы (ограничения ОС, сетевого протокола, компилятора).
2. **ДЛЯ ЧЕГО:** целевая гарантия безопасности или производительности.
3. **КАК:** точный технический механизм, алгоритм, структуры данных, код.
4. **ПОЧЕМУ НЕ ИНАЧЕ:** грабли, риски альтернатив и почему другие подходы сломают систему (ловушки коллизий, сбои экранирования, блокировки песочниц).

## 4. Форматирование и чистота
- Запрет на нумерацию файлов: никаких префиксов `01-`, `02-`. Имена файлов строго семантические (`core-architecture.md`, `master-spec.md`).
- Полный запрет на эмодзи и декоративные иконки во всех .md файлах.
- Максимальная плотность информации:
  - Сравнительные матрицы и таблицы вместо абзацев рассуждений.
  - Точные TypeScript-интерфейсы параметров и результатов.
  - Конкретные константы, флаги ОС, коды ошибок и регулярные выражения.
