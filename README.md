GhostVault — локальный шлюз между AI-агентом и моделью. Он заменяет пароли, токены и внутренние адреса на понятные псевдонимы, а в ответах восстанавливает значения для работы агента.

## Как это работает

Вы добавляете адрес сервиса в GhostVault под именем `API_URL`:

| Этап | Содержимое |
|---|---|
| Ваш запрос | Проверь `https://api.example.internal/health` |
| Запрос к модели | Проверь `$${<API_URL>}/health` |
| Ответ агенту | `curl https://api.example.internal/health` |

Модель составляет команду с псевдонимом. GhostVault возвращает исходный адрес перед передачей ответа агенту.

## Видно, что уходит в модель

![Интерфейс GhostVault: запрос к модели с заменёнными адресами и токеном, справа — список подстановок](docs/assets/dashboard.png)

*Настоящий интерфейс на демонстрационных данных.*

- **Свои правила.** Добавляйте секреты вручную или включайте автоматическое обнаружение.
- **Проверяемые замены.** Сравнивайте исходный запрос с тем, что отправлено модели, в одном интерфейсе.
- **Привычный рабочий процесс.** Подключайте AI-клиент через локальный адрес шлюза. Поддерживаются форматы OpenAI, Anthropic и Gemini, включая потоковые ответы и вызовы инструментов.

## Попробовать

Нужны Node.js 22.13+ и npm. Из корня репозитория:

```sh
cd ghostvault
npm run setup
npm run build
npm run demo
```

Откройте [локальный стенд](http://127.0.0.1:8766/dashboard). Он использует имитацию модели и базу в памяти — внешние API-ключи не нужны.

Для своего провайдера запустите `npm start`, откройте [панель подключений](http://127.0.0.1:8765/dashboard) и следуйте инструкции «Как подключить».

**Статус: в разработке.** Маскирование действует в [поддерживаемых полях API](docs/protocol-formats.md). Локальная база пока не зашифрована и может содержать секреты и историю запросов.
