# GhostVault

Локальный прокси для AI-клиентов: заменяет секреты в запросах к языковой модели на псевдонимы вида `$${<API_KEY>}` и восстанавливает значения в ответах, включая аргументы вызовов инструментов. Клиент подключается к адресу GhostVault вместо API провайдера.

Проект находится в разработке. Основа — TypeScript, Node.js, Fastify и SQLite; веб-интерфейс собран на собственном UI-kit.

## Что реализовано

- Ручные секреты и автоматическое обнаружение по настраиваемым правилам; ручные записи имеют приоритет.
- Обратимая замена исходных, URL-кодированных, Base64 и JSON-экранированных представлений секретов.
- Адаптеры OpenAI Chat Completions, OpenAI Responses, Anthropic Messages и Gemini, включая обёртку Antigravity. Обработка обычных JSON-ответов и SSE-потоков.
- Веб-интерфейс для подключений, секретов, правил и просмотра запросов, ответов и выполненных замен.
- JavaScript-хуки обработки трафика и MCP-инструменты для работы с хуками и контекстом запросов.

## Границы текущей версии

- Маскирование применяется к выбранным текстовым полям поддерживаемых форматов. Заголовки, URL, изображения и неизвестные JSON-структуры не проходят универсальную очистку. Наличие адаптера не означает проверенную совместимость со всеми клиентами и провайдерами.
- Локальная SQLite-база пока не зашифрована. В ней сохраняются ручные секреты и история запросов/ответов, которая может содержать исходные значения. Это не гарантия полного отсутствия утечек или готовности к корпоративной эксплуатации.
- Cache-Inspect-Get, постоянные сессии исполнения команд, WPF-подтверждения и шифрование хранилища остаются планами. Описания в спецификациях не следует считать перечнем готовых функций.

## Запуск из исходников

Требуются Node.js 22.13+ и npm. Из корня репозитория:

```sh
cd ghostvault
npm run setup
npm run build
npm start
```

Интерфейс: [http://127.0.0.1:8765/dashboard](http://127.0.0.1:8765/dashboard). Создайте или настройте подключение и укажите его локальный адрес в AI-клиенте; для внешнего провайдера нужна его авторизация.

По умолчанию база находится в `~/.ghostvault/vault.db`; путь задаётся переменной `GHOSTVAULT_DB_PATH`. Одну базу может обслуживать только один процесс GhostVault.

Для знакомства без внешних API-ключей после сборки выполните `npm run demo`: локальный mock-стенд с базой в памяти и интерфейсом на [127.0.0.1:8766/dashboard](http://127.0.0.1:8766/dashboard). Это имитация модели, а не облачное подключение.
